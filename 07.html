みんなこんにちは！

今回はHTML5のCanvas（キャンバス）を使って、JavaScriptで図形を描画する方法を学ぶよ！
Canvasを使うと、Webページ上に線や多角形、美しい幾何学模様などを自由に描くことができるんだ。

ということで、以下が今回の課題だよ～！
難しそうに見えても、数学の式や繰り返しの入れ子（2重ループ）の基本がわかればカンタンに描けるよ！

本日の課題一覧

  1. 正六角形を描画するプログラムを改良し、正N角形を描画するプログラムを作成しなさい。Nはテキストボックスから入力するものとする。（解説へ）
  2. スライドをよく読み、図形1🏁を描画するプログラムを作成しなさい。繰り返しの入れ子を使うこと(以下2問同様)。（解説へ）
  3. 図形2のような図形を描いてみましょう。（解説へ）
  4. 図形3のような図形を描いてみましょう。（解説へ）

💡 はじめてのCanvas！基本のキホン（まずはここからスタートしよう！）

  • キャンバス（お絵かきシート）を用意しよう！
    HTMLに <canvas id="canvas" width="200" height="200"></canvas> と書いて、描画する領域を作ろう！幅（width）と高さ（height）をタグの中でしっかり指定するのがポイントだよ。
  • 描画ペン（コンテキスト）を取り出そう！
    JavaScriptで let canvas = document.getElementById('canvas'); で要素を取得して、let ctx = canvas.getContext('2d'); で2D描画用のペン（コンテキスト）を取り出そう！これ以降の描画はすべてこの ctx を使って行うよ。
  • Canvasの座標（向き）を覚えよう！
    数学のグラフと違って、Canvasは「左上が原点 (0, 0)」だよ！右に進むほど X が大きくなり、下に進むほど Y が大きくなるよ。
  • 四角形をサクッと塗りつぶそう！
    色を ctx.fillStyle = 'black'; のように指定して、ctx.fillRect(x, y, 幅, 高さ); を実行するだけで四角形が塗れるよ！（今回の図形1〜3はコレを使うよ！）
  • パスを使って線や多角形を描こう！
    ctx.beginPath();（描き始め）→ ctx.moveTo(x, y);（始点へ移動）→ ctx.lineTo(x, y);（線を引く）→ ctx.closePath();（閉じる）→ ctx.stroke();（枠線を描く）や ctx.fill();（塗りつぶす）の順に進めよう！（正N角形で使うよ！）
  • 描き直すときはキレイに消去しよう！
    新しい図形を描く前に ctx.clearRect(0, 0, canvas.width, canvas.height); を呼ぶと、前回描いた絵を消して真っ白にリセットできるよ！

それでは、練習問題7-1から解説を始めるよ！
まずは六角形を描くコードを改良して、好きな正N角形を描けるようにしてみよう！

7-1. 正N角形を描画するプログラム

手順.
正六角形のプログラムをベースに、入力欄から角数Nを取得する。for文で 1 から N までループして各頂点へ線を結び、正N角形を描画する。

【問題】

正六角形を描画するプログラムを改良し、正N角形を描画するプログラムを作成しなさい。Nはテキストボックスから入力するものとする。

【考え方・ポイント】

  • 1周の角度をN等分しよう！
    円周は360度（2πラジアン）だよ。JavaScriptでは 2 * Math.PI と書くので、1周をN等分した角度 (2 * Math.PI / n) ずつ進めながら頂点を計算しよう！
  • 三角関数で頂点の座標を計算しよう！
    中心座標を (x, y)、半径を r とすると、i番目の頂点座標は次のように計算できるよ！
    X座標: x + Math.sin(i * 2 * Math.PI / n) * r
    Y座標: y - Math.cos(i * 2 * Math.PI / n) * r
  • for文で各頂点へ線をつなごう！
    moveTo で最初の頂点に移動したら、for (let i = 1; i <= n; i++) のループで各頂点へ lineTo で線をつなぎ、最後に closePath で図形を閉じよう！
  • 描画する前に画面をクリアしよう！
    新しい角数を描く前に ctx.clearRect(0, 0, canvas.width, canvas.height); で前回の図形をきれいに消去しよう！

【サンプルコード（ヒント）】

function drawPolygon() {
  let canvas = document.getElementById('canvas71');
  let ctx = canvas.getContext('2d');

  // 前回の描画をクリアしよう
  ctx.clearRect(0, 0, canvas.width, canvas.height);

  // テキストボックスから角数Nを取得しよう
  let n = /*   テキストボックス polyN の値を数値として取得する */;
  if (n < 3) {
    alert("3以上の整数を入力してください");
    return;
  }

  let x = 100; // 中心のX座標
  let y = 100; // 中心のY座標
  let r = 80;  // 半径

  ctx.lineWidth = 3.0;
  ctx.strokeStyle = 'black';
  ctx.fillStyle = 'lightgrey';

  ctx.beginPath();
  // 最初の頂点へ移動しよう (i = 0)
  ctx.moveTo(x + Math.sin(0 * 2 * Math.PI / n) * r,
             y - Math.cos(0 * 2 * Math.PI / n) * r);

  // 1 から n まで繰り返し線をつなごう
  for (let i = 1; /*   繰り返しの終了条件（iがn以下） */; i++) {
    ctx.lineTo(/*   i番目のX座標（三角関数で計算） */,
               /*   i番目のY座標（三角関数で計算） */);
  }

  ctx.closePath(); // パスを閉じよう
  ctx.fill();      // 塗りつぶそう
  ctx.stroke();    // 枠線を引こう
}

ヒント：六角形のコードにあった / 6 の部分を変数 / n に置き換えて、for文の終了条件を i <= n にするだけだよ！Nを大きくすると円に近づいていくのが面白いね！

7-2. 図形1🏁 市松模様（チェッカーフラッグ）を描画する

手順.
繰り返しの入れ子（2重ループ）を使って、10行×10列のマス目を走査する。(行番号 + 列番号) が偶数なら黒、奇数なら白を ctx.fillRect() で塗りつぶす。

【問題】

スライドをよく読み、図形1🏁（市松模様）を描画するプログラムを作成しなさい。繰り返しの入れ子（2重ループ）を使うこと(以下2問同様)。

【考え方・ポイント】

  • マス目のサイズと位置を計算しよう！
    キャンバスの大きさは幅200px、高さ200pxだよ。10×10のマスを作るので、1マスの大きさは 200 ÷ 10 = 20px になるよ！行番号を i、列番号を j とすると、各マスの左上座標は (j * 20, i * 20) で表せるよ。
  • 繰り返しの入れ子（2重ループ）を作ろう！
    外側のループで行（縦方向 i = 0〜9）、内側のループで列（横方向 j = 0〜9）を回して、全100マスを順番に走査しよう！
  • 偶数・奇数で色を交互に切り替えよう！
    市松模様は「行番号 + 列番号」が偶数なら黒、奇数なら白と判定すれば綺麗に交互になるよ！判定式には (i + j) % 2 === 0 を使おう！
  • 四角形を塗りつぶしてマス目を描こう！
    色を設定したら、ctx.fillRect(j * size, i * size, size, size); で1マスずつ塗りつぶそう！

【サンプルコード（ヒント）】

function drawPattern1() {
  let canvas = document.getElementById('canvas');
  let ctx = canvas.getContext('2d');
  ctx.clearRect(0, 0, canvas.width, canvas.height);

  let size = 20; // 1マスの幅と高さ

  // 外側のループ：行（縦方向 i = 0〜9）
  for (let i = 0; i < 10; i++) {
    // 内側のループ：列（横方向 j = 0〜9）
    for (let j = 0; j < 10; j++) {
      // (i + j) が偶数なら黒、奇数なら白にしよう
      if (/*   (i + j) が偶数かどうかを判定する条件式   */) {
        ctx.fillStyle = 'black';
      } else {
        ctx.fillStyle = 'white';
      }
      // マス目を塗りつぶそう
      /*   ctx.fillRect を使ってマスを描画する   */;
    }
  }
}

ヒント：外側のループが行、内側のループが列を表すよ！(i + j) % 2 === 0 という条件式を使うと、チェッカーフラッグのように隣り合うマス同士で色が交互に切り替わるんだ！

7-3. 図形2 斜線ストライプパターンを描画する

手順.
2重ループの中で、(行番号 + 列番号) を4で割った余りを判定する。余りが0のマスを黒、それ以外を白にすることで、4マス周期の斜線パターンを描画する。

【問題】

図形2のような、斜め方向に走る縞模様（4マス周期のストライプ）を描くプログラムを作成しなさい。練習問題7-2と同様に繰り返しの入れ子を使うこと。

【考え方・ポイント】

  • 右上がりの斜めラインの性質を見つけよう！
    図形2を観察すると、右上がりの斜めライン上に黒マスが並んでいるよ！斜め方向のマスは (i + j) を計算すると同じ値になる性質があるよ。
  • 4で割った余り（周期性）を活用しよう！
    4マスごとに同じ斜線パターンが繰り返されているので、(i + j) % 4 を計算しよう！余りが 0 のマスだけを黒色にし、それ以外のマスを白色にしよう！
  • 繰り返しの入れ子で全マスを描こう！
    図形1と同様に、行 i と列 j の2重ループを回して描画しよう！

【サンプルコード（ヒント）】

7-4. 図形3 3色の縞模様を描画する

手順.
図形2の考え方を発展させ、4で割った余りに応じて「黒」「灰色」「白」の3色に分岐する。if ... else if ... else を使って多色ストライプを描画する。

【問題】

図形3のような、黒・白・灰色の3色からなる斜めストライプ模様を描くプログラムを作成しなさい。繰り返しの入れ子と条件分岐を活用すること。

【考え方・ポイント】

  • 4で割った余りに応じて3色に分岐しよう！
    図形3は、図形2のパターンの間に灰色（グレー）が挟まっているよ！周期は同じ4マス周期なので、余り rem = (i + j) % 4 の値（0, 1, 2, 3）に応じて3色を切り替えよう！
    • 余りが 0 のとき：黒（black）にしよう！
    • 余りが 2 のとき：灰色（lightgray）にしよう！
    • 余りが 1 または 3 のとき：白（white）にしよう！

    3通りの色を分岐するために、if (rem === 0) { ... } else if (rem === 2) { ... } else { ... } の構文を使おう！
  • マス目を塗りつぶして描画しよう！
    分岐で色が決まったら、ctx.fillRect(j * size, i * size, size, size); で描画しよう！
