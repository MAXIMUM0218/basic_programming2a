2-4. クリックで画像を10pxずつ大きくする

手順.
getAttributeで現在のwidthを取得し、10増やしてsetAttributeで設定する。

【サンプルコード】

<img src="img2026/maxi2.jpg" width="200" id="ex02_02">
<input type="button" value="画像を大きくする" onclick="large();">

<script>
function large() {
  // width値を取得して数値に変換
  let w = Number(document.getElementById('ex02_02').getAttribute('width'));
  // 10増やす
  w = w + 10;
  // 新しい値を設定
  document.getElementById('ex02_02').setAttribute('width', w);
}
</script>

実行結果



2-5. 横幅が300pxを超えたら大きくならないようにする

手順.
if文を使い、widthが300以下の時だけ大きくする処理を行う。

【サンプルコード】

<script>
function largeLimit() {
  let w = Number(document.getElementById('ex02_03').getAttribute('width'));
  if ( ______ ) {
    w = w + 10;
    document.getElementById('ex02_03').setAttribute('width', w);
  } else {
    alert("これ以上大きくできません！");
  }
}
</script>

実行結果



ヒント：画像の幅が 300px を超えたら「もう大きくできない」と判断する条件を入れよう！

次は練習問題3だよ！
JavaScriptを使って、文字色やフォントサイズ、背景色を動的に変更する方法を学んでいこう！

3-1. ボタンをクリックすると文字色とフォントが変わる

手順.
変数colorを用意してif文で色を切り替え、変数sizeを+1してpxを付ける。

【サンプルコード】

<p id="text_prob31">このテキストが変わります</p>
<input type="button" value="変更する" onclick="changeText();">

<script>
let size = 16;
let color = 'black';

function changeText() {
  if ( ______ ) {
    color = 'red';
  } else {
    color = 'black';
  }
  document.getElementById('text_prob31').style.color = ______;

  size = size + 1;
  document.getElementById('text_prob31').style.fontSize = ______;
}
</script>

実行結果

このテキストが変わります

ヒント：文字色は if で black と red を切り替える。あとで style.color と style.fontSize を代入するのがポイントだよ！

3-2. テキストボックスに入力した色を背景色にする

<input type="text" id="color_input" placeholder="red, blueなど">

<script>
function changeBg() {
  let inputColor = document.getElementById('color_input').value;
  document.getElementById('bg_prob32').style.backgroundColor = ______;
}
</script>

実行結果

背景色が変わる領域

ヒント：入力した文字は変数に入れて、それを style.backgroundColor に代入するだけ！

3-4. クリックで取り消し線が引かれたり消えたりする

手順.
textDecorationが空文字なら'line-through'を、そうでなければ空文字を代入する。

【サンプルコード】

<p id="strike_prob34" onclick="toggleStrike();" style="cursor: pointer;">ここをクリックすると取り消し線がつきます</p>

<script>
function toggleStrike() {
  let el = document.getElementById('strike_prob34');
  if ( ______ ) {
    el.style.textDecoration = 'line-through';
  } else {
    el.style.textDecoration = '';
  }
}
</script>

実行結果

ここをクリックすると取り消し線がつきます（クリック！）

ヒント：今の状態が空文字かどうかで、取り消し線を付けるか外すかを切り替えよう！
