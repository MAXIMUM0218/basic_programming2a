4-1. クラス名がcccのPタグの背景色を変更する

手順.
getElementsByClassName('ccc') でクラスcccの要素を全て取得し、for文でループして背景色を変更する。

【問題】

以下のようなPタグがあるとき、クラス名がcccの要素について、テキストボックスに入力された色を背景色に設定するプログラムを作成しなさい。

<p class="aaa">要素1(aaa)</p>
<p class="aaa bbb">要素2(aaa bbb)</p>
<p class="ccc aaa bbb">要素3(ccc aaa bbb)</p>
<p class="aaa ccc bbb">要素4(aaa ccc bbb)</p>
<p class="aaa bbb">要素5(aaa bbb)</p>

【サンプルコード（ヒント）】

function ccc() {
  // まず対象の段落の背景色を初期化
  reset();
  // テキストボックスから色を取得
  let color = document.getElementById('colortext').value;
  // クラス名cccの要素を取得
  let elems = document.getElementById('demo-p-container').getElementsByClassName('ccc');
  // ループして全要素の背景色を変更
  for (let i = 0; i < elems.length; i++) {
    elems[i].style.backgroundColor = color;
  }
}

実行結果

ヒント：getElementsByClassName('ccc') はクラスcccを持つ要素を全部まとめて取得できるよ！for文でループしてそれぞれの backgroundColor を変更しよう！

4-2. クラス名がaaa, bbbのPタグの背景色を変更する

手順.
getElementsByClassName('aaa bbb') でクラスaaa・bbb両方を持つ要素を取得する。ボタンクリック時はまず reset() で対象の段落の背景色を初期化してから変更する。

【問題】

クラス名がaaaかつbbbのPタグの背景色を変更するプログラムを作成しなさい。

  • 複数のクラス名を指定するには、document.getElementsByClassName('aaa bbb')のように、クラス名をスペースで区切って指定します。これで「aaa と bbb の両方を持つ要素」だけが取得されます。
  • ボタンがクリックされた時には最初に対象の段落の背景色を初期状態（透明）に戻します。
    初期化には .style.backgroundColor = 'transparent' を使います。
    この処理を reset() という関数として定義しておき、各ボタンのクリック時に最初に呼び出します。

【サンプルコード（ヒント）】

// 対象の段落の背景色を初期化する関数
function reset() {
  let allP = document.getElementById('demo-p-container').getElementsByTagName('p');
  for (let i = 0; i < allP.length; i++) {
    allP[i].style.backgroundColor = 'transparent';
  }
}

function aaabbb() {
  // まず対象の段落の背景色を初期化
  reset();
  // テキストボックスから色を取得
  let color = document.getElementById('colortext').value;
  // クラス名aaa と bbb 両方を持つ要素を取得（スペース区切りで指定）
  let elems = document.getElementById('demo-p-container').getElementsByClassName('aaa bbb');
  for (let i = 0; i < elems.length; i++) {
    elems[i].style.backgroundColor = color;
  }
}

動作確認：
・「cccの色を変更」→ 要素3・4が着色
・「aaaとbbbの色を変更」→ 要素2・3・4・5が着色
・ボタンを押すたびに reset() で対象段落の色を初期化

ヒント：getElementsByClassName('aaa bbb') はクラスaaaとbbbを両方持つ要素だけを取得するよ！ボタンを押すたびにまずreset()で初期化してから色を付けよう！

4-3. getElementsByTagName()でpタグの数を数える

手順.
getElementsByTagName('p') でページ内の全pタグを取得し、.length で個数を調べて alert() で表示する。

【問題】

pタグが複数含まれているページを作り、getElementsByTagName()を使ってpタグの数を数え、その数をalert()で表示するプログラムを作成しなさい。ボタンをクリックすると実行されるようにすること。
※ 配列の要素数は 配列名.length で取得できる。

【サンプルコード（ヒント）】

function countP() {
  // pタグを全て取得する
  let elems = document.getElementsByTagName('p');
  // 個数を alert() で表示する
  alert('pタグの数：' + elems.length);
}

4-4. テキストボックスで指定したタグの数を表示する

手順.
テキストボックスからタグ名を取得し、getElementsByTagName() の引数にその変数を直接渡して、取得件数を alert() で表示する。

【問題】

上を改良し、テキストボックスからタグ名を入力し、そのタグの数をalert()で表示するプログラムを作成しなさい。ボタンをクリックすると実行されるようにすること。
※ getElementsByTagName()の中にはテキストボックスから取得した変数を直接書けばよい。

【サンプルコード（ヒント）】

function countX() {
  // テキストボックスからタグ名を取得する
  let tagName = document.getElementById('a').value;
  // 取得したタグ名で要素を全て取得する
  let elems = document.getElementsByTagName(tagName);
  // 個数を alert() で表示する
  alert(tagName + 'タグの数：' + elems.length);
}

実行結果


※ ページ全体のタグ数を表示します

ヒント：getElementsByTagName(変数) のように、変数を直接引数に渡せるよ！テキストボックスに "div" や "h1" と入力して試してみよう！

4-5. 時間割表で「重要」「微妙」ボタンにより背景色を変更する

手順.
tableタグで時間割を作成し、各科目のtdタグにクラスを付けておく。「重要」ボタンでは重要科目のクラスを、「微妙」ボタンでは微妙科目のクラスを getElementsByClassName() で取得して背景色を変更する。

【問題】

tableタグを使って時間割表を作り、「重要」ボタンをクリックすると落とせない科目名の背景色が赤に、「微妙」ボタンをクリックすると落としてもよい科目名の背景色が青になるようにしなさい（科目は適当でよい）。

【サンプルコード（ヒント）】

<!-- HTML -->
<td class="important">必修科目A</td>
<td class="mild">選択科目B</td>

<!-- JavaScript -->
function markImportant() {
  let elems = document.getElementsByClassName('________________');
  for (let i = 0; i < elems.length; i++) {
    elems[i].style.backgroundColor = '________________';
  }
}
function markMild() {
  let elems = document.getElementsByClassName('________________');
  for (let i = 0; i < elems.length; i++) {
    elems[i].style.backgroundColor = '________________';
  }
}
