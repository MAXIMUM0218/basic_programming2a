4-1. クラス名がcccのPタグの背景色を変更する

手順.
getElementsByClassName('ccc') でクラスcccの要素を全て取得し、for文でループして背景色を変更する。

【問題】

以下のようなPタグがあるとき、クラス名がcccの要素について、テキストボックスに入力された色を背景色に設定するプログラムを作成しなさい。

<p class="aaa">段落1</p>
<p class="bbb">段落2</p>
<p class="ccc">段落3</p>
<p class="aaa bbb">段落4</p>
<p class="bbb ccc">段落5</p>
<p class="aaa bbb ccc">段落6</p>

【サンプルコード（ヒント）】

function changeCccColor() {
  // まず全要素の背景色を初期化
  reset();
  // テキストボックスから色を取得
  var color = document.getElementById('________________').value;
  // クラス名cccの要素を取得
  var elems = document.getElementsByClassName('________________');
  // ループして全要素の背景色を変更
  for (var i = 0; i < elems.length; i++) {
    elems[i].style.backgroundColor = ________________;
  }
}

ヒント：getElementsByClassName('ccc') はクラスcccを持つ要素を全部まとめて取得できるよ！for文でループしてそれぞれの backgroundColor を変更しよう！

4-2. クラス名がaaa, bbbのPタグの背景色を変更する

手順.
getElementsByClassName('aaa bbb') でクラスaaa・bbb両方を持つ要素を取得する。ボタンクリック時はまず reset() で背景色を初期化してから変更する。

【問題】

クラス名がaaaかつbbbのPタグの背景色を変更するプログラムを作成しなさい。

  • 複数のクラス名を指定するには、document.getElementsByClassName('aaa bbb')のように、クラス名をスペースで区切って指定します。これで「aaa と bbb の両方を持つ要素」だけが取得されます。
  • ボタンがクリックされた時には最初に背景色を初期状態（透明）に戻す必要があります。
    初期化には .style.backgroundColor = 'transparent' を使います。
    この処理を reset() という関数として定義しておき、各ボタンのクリック時に最初に呼び出します。

【サンプルコード（ヒント）】

// 全要素の背景色を初期化する関数
function reset() {
  var allP = document.getElementsByTagName('p');
  for (var i = 0; i < allP.length; i++) {
    allP[i].style.backgroundColor = 'transparent';
  }
}

function changeAaaBbbColor() {
  // まず全要素の背景色を初期化
  reset();
  // テキストボックスから色を取得
  var color = document.getElementById('________________').value;
  // クラス名aaa と bbb 両方を持つ要素を取得（スペース区切りで指定）
  var elems = document.getElementsByClassName('________________');
  for (var i = 0; i < elems.length; i++) {
    elems[i].style.backgroundColor = ________________;
  }
}

4-5. 時間割表で「重要」「微妙」ボタンにより背景色を変更する

手順.
tableタグで時間割を作成し、各科目のtdタグにクラスを付けておく。「重要」ボタンでは重要科目のクラスを、「微妙」ボタンでは微妙科目のクラスを getElementsByClassName() で取得して背景色を変更する。

【問題】

tableタグを使って時間割表を作り、「重要」ボタンをクリックすると落とせない科目名の背景色が赤に、「微妙」ボタンをクリックすると落としてもよい科目名の背景色が青になるようにしなさい（科目は適当でよい）。

【サンプルコード（ヒント）】

<!-- HTML -->
<td class="important">必修科目A</td>
<td class="mild">選択科目B</td>

<!-- JavaScript -->
function markImportant() {
  var elems = document.getElementsByClassName('________________');
  for (var i = 0; i < elems.length; i++) {
    elems[i].style.backgroundColor = '________________';
  }
}
function markMild() {
  var elems = document.getElementsByClassName('________________');
  for (var i = 0; i < elems.length; i++) {
    elems[i].style.backgroundColor = '________________';
  }
}
